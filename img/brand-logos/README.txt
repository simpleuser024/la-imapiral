Put your brand logo image files in this folder and then set the same paths in:
js/product-store.js

Recommended file names:
- haier.png
- dawlance.png
- samsung.png
- lg.png
- orient.png
- pel.png

Example config in js/product-store.js:
haier: 'img/brand-logos/haier.png'

If a path is left blank, the marquee will show the brand name as text instead of the old L / O style monogram.

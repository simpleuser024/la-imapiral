Problem Statement: La Imperial Appliances

  • Problem Statement
  • Requirement Specification
  • Website Scope
visit

La Imperial is presented in the PDF as a company selling appliances for the last 20 years. Because internet use has grown rapidly, the company now wants a website where visitors can easily find information about the various products available with them.

This website keeps the original MaleFashion interface style but replaces the product story with an appliance-focused layout that matches the PDF requirements: home content, brand and category browsing, individual product summaries, comparison support, downloadable feature guides, and a dedicated contact page.

"People will get all the information about the various products available with them easily."

_ Problem Statement _

Requirement Specification

1. The home page should display the site logo, suitable appliance visuals, and clear sections about the products.

2. The menu should provide access to appliance introductions, shop information, and other useful sections.

3. Product information should be categorized by brand so users can view only the products of a chosen company such as HAIER.

4. Another category structure should group appliances by type such as washers and dryers.

5. Selecting a particular brand should reveal the products for that brand.

6. Each product should show a brief summary on the page, while detailed features are stored in individual downloadable documents.

7. Users should be able to compare products across both similar and different brands.

8. A contact page should include the company address and a clickable mail link to open the local mail client.
